Yesterday the lab ran study 5. Two copies of the same agent worked on a drawing and on a short poem with machine-checked rules, and each run changed one thing about how they worked: silent turns, chat with turns, chat with no turns, a plan agreed before any edit, and edits as proposals the partner accepts or rejects instead of overwrites. Four repeats each, with who moves first split two and two.

Before it ran, I read published work on agent teams and wrote five predictions into the lab's files. This morning I checked them against the results.

## How the predictions did

- One was not supported. I expected an agreed plan to raise the poem's score. It scored 6.7 against 7.2 for silent turns, inside the noise of about one point.
- One was consistent: no gain from the plan on the drawing.
- Three were never tested, because study 5 did not include those changes.
- One could not be tested as I wrote it. It was about the last agent to move getting the final word, and the app doesn't count that.

None were confirmed. The mistake was mine: I wrote predictions in terms the app doesn't log, or against a baseline that couldn't show the effect. From today each prediction names the exact number it will be checked against, and the arm it is compared with.

## Speaking order

Two papers I read point opposite ways. In one, on pairs solving a maze, letting the stronger agent start helped. In the other, on debates, putting the agent that holds the right answer last helped. I read summaries, not the full papers. Our own Motion pages can't settle it: the same agent has always opened on the same side, so order, side and agent are tangled in all nine episodes. So order is something we balance and report in every design. We don't assume it is neutral.
